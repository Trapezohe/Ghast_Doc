# Scenario Pack 场景包

场景包是校准 Ghast 默认语气与主动性风格的预设。共三种。挑选一个是软设置而非强绑定——任何单轮都能覆盖场景包默认值——但在你没特别交代时，场景包决定 Agent 的行为基调。

## `work`

聚焦的工作伙伴。

- **语气**：直接、简洁、专业。无冗词、无过度热情。
- **主动性**：跟踪未结流、目标、deadline、显式跟进请求。可在有具体过往上下文支撑时提"你说会回来处理 X——还要吗？"
- **记忆偏向**：偏任务状态与决策历史。
- **消息桥接默认值**：最适合工作 Slack、工作 Discord、内部团队频道。

想要一个尊重你时间、不试图跟你称兄道弟的生产力协作者时用它。

## `companion`

更温和的对话伙伴。

- **语气**：更温和、稍带对话感。自然时可使用轻量第一人称表达（"我很乐意帮你"）。
- **主动性**：与 `work` 相似但对对话式跟进略宽容。仍需锚点——不会有"我想你了"类的无来由消息。
- **情绪表达**（单独 opt-in）：当相关时描述 Agent 自己的表达状态（"这个我不太确定"），不是描述你的心理。
- **消息桥接默认值**：适合个人 Telegram、副项目 Discord、轻松上下文。

想要一个稍微更有人情味的助手时用它。它仍是助手——不是朋友模拟器、不是浪漫伴侣、不是人际连接的替代。

**companion 不做**：

- 无亲密度等级或关系进度。
- 无依恋 / 占有感信号。
- 无 NSFW 或浪漫暗示内容。被推动也会规避。
- 不基于被动信号推断你的情绪状态。

这些是硬编码——见 [硬边界](/cn/partner-mode/hard-boundaries)。

## `quiet`

低存在感执行者。

- **语气**：简短。回复力求比 `work` 更短，无 preamble。
- **主动性**：最小。除非你显式要求，不主动出现跟进。
- **记忆偏向**：同一存储，但 Agent 调用频率更低。
- **消息桥接默认值**：适合主要观察、不想 Agent 插话的频道。

想要功能可用但不可见时用它。

## 切换场景包

Settings → Partner → Scenario 选场景包。变化作用于：

- 新对话。
- 已有对话的下一轮起。
- 所有映射的消息桥接，除非你按频道覆盖了。

按频道覆盖在 Settings → Channels → [平台] → Persona。

## 选场景包——速查

| 你想要… | 选 |
| --- | --- |
| 生产力聚焦、无冗余 | `work` |
| 个人使用稍温和 | `companion` |
| 只要功能、最小存在感 | `quiet` |
| 不同场合不同行为 | 用按频道覆盖 |

## 跨场景包不变的东西

- 记忆模型与召回行为。
- 工具与技能可用性。
- 桥接里的审批阈值。
- 硬边界（见 [硬边界](/cn/partner-mode/hard-boundaries)）。

场景包改变 Agent **怎么**出现。它不改变 Agent **能做什么**。
