# Desktop 更新日志

桌面客户端面向用户的变化。版本按时间倒序。

## 0.1.2 — 2026-05-21

- 改进 Computer Use，包括 playbook 中更清晰的应用专用指引
- 模型选择器下工具使用与文件写入更稳定
- 为 Partner Mode 主动消息增加提醒与未读提示
- 增加基于记忆的 Home 提醒，提示值得继续的未结流

## 0.1.1 — 2026-05-18

- 改进 Coding Mode，开发场景更可靠
- Ghast 更具个性，跨会话更善于记住你的偏好
- 改进记忆质量、语义搜索、合并器自动清理
- 增加 X 支持：用你已登录的账号搜索、起草、发帖
- 改进网页搜索的测试、隐私保护、活动记录器性能

## 如何阅读本更新日志

每条都是简短的用户面摘要。内部重构、构建流水线变更、纯代码修复不在此列——它们在源仓库里。

如果某个版本引入新权限、链上交互或边界变化，相应的安全与参考页也会反映该变化。
