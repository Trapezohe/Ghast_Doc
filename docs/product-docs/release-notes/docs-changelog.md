# 文档更新日志

本文档集的重要内容变化。外观修订、链接修复、错字订正不列出。

## 2026-05-24 — 整套重写

反映 Ghast AI 产品定位的整套重写：

- **以桌面为主**——macOS Electron 客户端是主要入口；旧版"Chrome 侧边栏 + Companion"框架退场。
- **新章节：Web3 基础设施**——0G Compute、0G Storage、钱包与密钥托管、推理模式、TEE 确认。
- **新章节：Computer Use**——概览、macOS 权限、每应用审批 Gate、应用 playbook、安全边界。
- **新章节：Partner Mode**——概览、场景包（`work`、`companion`、`quiet`）、Initiative 引擎、UUM、硬边界。
- **更新章节：远程消息通道**——覆盖五个平台（Telegram、Discord、Slack、飞书、微信），取代之前以 Telegram 为中心的覆盖。
- **更新章节：浏览器扩展**——重定位为小型中继，不再是主要产品入口。
- **更新章节：安全**——按面的显式信任边界；诚实的威胁模型边界；这套栈防什么、不防什么。
- **新章节侧栏与导航**——顶部导航增加 Web3，与 Desktop、Security 并列。

之前以扩展为中心、附带可选 "Companion" 本地服务的文档已退场，由上述结构替代。
