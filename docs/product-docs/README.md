# Ghast AI 文档

欢迎使用 Ghast AI 用户手册。Ghast AI 是一个由链上算力驱动、以桌面为主体的 macOS AI 伙伴：推理流量经过 **0G Compute** 网络，个人数据通过 **0G Storage** 端到端加密备份，同一个 Agent 可以从桌面延伸到浏览器、macOS 应用和团队日常使用的消息平台。

本手册是产品当前能力、配置流程和安全边界的唯一可信来源。

## 文档边界

- 本手册只描述当前产品里已经存在的能力。
- 代码中存在但未作为默认入口的能力会明确写成 **「已实现但不作为默认入口」**，不会写成普通用户当前应直接使用的功能。
- 参考页用于集中列出字段、状态和范围说明；其余页面均按用户手册口径编排，不是工程文档。

## 适用人群

本手册面向 Ghast AI 的普通用户与集成方。面向开发者的内容（如自定义技能开发、应用打包、代码贡献）不在本手册范围内，详见源代码仓库。
