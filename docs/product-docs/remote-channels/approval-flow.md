# 审批流

桥接面对真实频道里的真实人，所以比本地对话标准更严。审批流是 Agent 暂停、在 Ghast Desktop 弹出确认卡片、等待你做出决定的瞬间。

## 什么会触发审批

Agent 不会对每个回复都停。琐碎对话自动发出。审批触发条件：

| 触发 | 原因 |
| --- | --- |
| **长回复** | 超过可配阈值（默认 800 字符）。 |
| **出站文件 / 附件** | 向频道发送媒体。 |
| **工具调用有副作用** | Agent 用的工具带 `writes: true` 或 `destructive: true`——例如往另一个频道发消息、改远端状态。 |
| **群里非 actor 的消息** | 不在频道授权 actor 列表里的用户让 Agent 做事。 |
| **新映射频道的首次回复** | 视为 sanity check；之后在该频道的回复不再弹窗。 |
| **Auto-apply review 命中** | Partner Mode 的自动应用规则命中暂停条件。 |

大多数都可在 Settings → Channels → [平台] → Approval Rules 调整。

## 审批卡片显示什么

卡片出现在桌面客户端（不是远程频道）。内容：

- 频道名与平台。
- 触发消息的用户身份。
- Agent 打算发送的消息预览。
- Agent 即将做的工具调用列表（含参数）。
- 三按钮：**发送**、**编辑后发送**、**取消**。

卡片显示期间，Agent 停滞。其他频道与会话继续工作——只有等待审批的那个暂停。

## 编辑后发送

Agent 草稿 90% 正确的情况常见。「编辑后发送」打开内嵌编辑器让你在发布前微调。编辑后的内容会被发送；Agent 不重新生成。

## 超时

30 分钟内不响应视为取消。Agent 会在频道里发简短 reaction（"我先没动手——还要继续就告诉我"，可按频道配置）。

## 日志

每次审批（批准或拒绝）都记录在 Settings → Channels → [平台] → Approval Log。日志显示：

- 时间戳
- 频道 / 用户
- 动作类型
- 决定
- 最终发送内容（如已发）

便于复盘或合规。

## 绕过审批

可以按频道、按平台、按工作区降低审批门槛。合理选择：

- **Telegram 的 DM**——绕过（只有你一个人）。
- **高信任内部 Slack 频道**——短回复绕过，带副作用的工具调用保留。
- **对外频道**——所有都保留。

Settings → Channels → [平台] → Approval Rules 里可设阈值。

## 不触发审批的情况

即使不是琐碎工作，下列场景也不暂停：

- **Reaction**——emoji reaction 太轻量，不门禁。
- **确认与承接**——"收到，处理中" 自动发。
- **已批准过的工具调用形状**——同一工具调用形状近期已批准过，短时间内重复调用直接放行。

这些是便利，可在规则里逐项禁用。
