# 登录与激活

按症状索引。

## 收不到验证码

| 可能原因 | 处理 |
| --- | --- |
| 邮件进了垃圾箱 | 查垃圾箱；标记为非垃圾 |
| 邮件商较慢 | 等 30 秒，重新申请 |
| 邮箱地址打错 | 取消，用正确邮箱重试 |
| 邮件后端故障 | 等 5 分钟再试或改用 Google OAuth |

## 验证码被拒为无效

| 可能原因 | 处理 |
| --- | --- |
| 过期（>5 分钟） | 重新申请 |
| 输错 | 重新输入，注意相似字符（0/O、1/l） |
| 用了两次 | 验证码一次性；申请新的 |

## Google OAuth 没回到应用

| 可能原因 | 处理 |
| --- | --- |
| macOS deep-link handler 未注册 | Cmd-Q 完全退出 Ghast，从 `应用程序` 重新打开，再试 |
| 装了多个 Ghast 版本 | 删掉旧版本；deep link 只解析到一个应用 |
| 默认浏览器处理回调异常 | 把 Safari 设为默认浏览器再试 |

## 出现 Activation 屏但你没有码

| 可能原因 | 处理 |
| --- | --- |
| 你在受邀的预览渠道 | 从邀请源（Discord / X）拿到码 |
| 账号从另一渠道迁移 | 联系维护者 |

## Onboarding 回到登录页循环

| 可能原因 | 处理 |
| --- | --- |
| 后端 session 没建立 | 检查网络；企业代理有时拦截 auth 回调 |
| Profile Vault 里的 auth 状态冲突 | 完全退出登录；能识别的话删掉 `~/Library/Application Support/Ghast/profiles/<出问题的>`，重试 |

## 钱包步骤绑定失败

| 可能原因 | 处理 |
| --- | --- |
| 钱包签名失败（助记词打错） | 用正确助记词重试 |
| 绑定挑战期间网络故障 | 重试；挑战会重生成 |
| 两个 Profile 想绑定同一地址 | 第二个 Profile 用不同钱包，或合并 Profile 删掉一个 |

## 登录成功后钱包不可用

| 可能原因 | 处理 |
| --- | --- |
| 应用被强制退出，Vault Key 没重新签发 | 重新登录 |
| 加密钱包文件损坏 | 该设备上钱包可能不可恢复。有助记词的话新建 Profile 导入。 |
