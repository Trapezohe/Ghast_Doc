# Memory 与同步

按症状索引。

## 记忆召回什么都不出

| 可能原因 | 处理 |
| --- | --- |
| 召回阈值太高 | Settings → Memory → 相似度阈值；试 0.65 |
| 嵌入供应商换了但重嵌入没完成 | 等重嵌入；查 Settings → Memory → 统计 |
| 存储为空（刚装） | 通过使用 Agent 累积起来 |
| 工作区过滤排除了正确记忆 | 查当前工作区 |

## 旧记忆突然不匹配

| 可能原因 | 处理 |
| --- | --- |
| 嵌入供应商被换 | 旧 embedding 被丢；重嵌入进行中 |
| 合并器把它们 archive 进另一摘要 | 在 Settings → Memory 搜索 archived |

## 记忆静默写入 / 让我意外

| 可能原因 | 处理 |
| --- | --- |
| 活动记录器生成了候选记忆 | Settings → Memory → 按来源 = activity 过滤 |
| 某技能在写 | 检查 Agent 的工具调用卡 |
| 合并器合并了 | 查合并器最近运行 |

## 删不掉某条记忆

| 可能原因 | 处理 |
| --- | --- |
| 软删除等待最终化 | 等下次合并器运行，或手动跑一次 |
| 该记忆被 UUM 合并引用 | 先清掉引用它的 UUM 字段 |

## 0G Storage 同步显示 "failed"

| 可能原因 | 处理 |
| --- | --- |
| 钱包没 OG 付链上指针 | 给钱包发少量 OG |
| 存储 indexer 不可达 | 查到 `indexer-storage-turbo.0g.ai` 的连通性 |
| 快照过大 | 关一类后重试；大类别耗时较长 |

## 跨设备恢复失败

| 可能原因 | 处理 |
| --- | --- |
| 新设备导入了不同钱包 | 解密失败——必须用同一钱包 |
| 源设备没开同步 | 没有快照；先在源设备开启同步 |
| Pointer Registry RPC 问题 | 稍后再试 |

## 活动记录器什么都不显示

| 可能原因 | 处理 |
| --- | --- |
| 录制未开启（默认） | Settings → Activity → 启用 |
| 该应用在静音列表 | 查静音列表 |
| 录制是在你关心的时间段之后才开的 | 不能回填历史 |

## 嵌入切换确认没出现

| 可能原因 | 处理 |
| --- | --- |
| 你在同一次保存里换了供应商 | 提示在保存时出现；错过的话 Settings → Memory → 重新嵌入 |

## Memory 面板看到的记忆数比预期少

| 可能原因 | 处理 |
| --- | --- |
| 有过滤器（来源、标签、日期） | 清掉面板顶部的过滤器 |
| Archive 视图收起 | 切换归档视图 |
