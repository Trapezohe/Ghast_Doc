# Desktop Changelog

User-facing changes to the desktop client. Versions land alphabetically by date.

## 0.1.2 — 2026-05-21

- Improved Computer Use, including clearer app-specific guidance for the playbooks
- More reliable tool use and file writing across the model picker
- Added reminders and unread indicators for proactive Partner Mode messages
- Added memory-based home reminders for open loops worth continuing

## 0.1.1 — 2026-05-18

- Improved Coding Mode for more reliable development work
- Made Ghast more personal and better at remembering your preferences across sessions
- Improved memory quality, semantic search, and automatic cleanup via consolidation
- Added X support for search, drafting, and posting from your signed-in account
- Improved web search testing, privacy protection, and Activity Recorder performance

## How to read this changelog

Each release line is a short, user-facing summary. Internal refactors, build pipeline changes, and code-only fixes are not listed here — they're in the source repository.

If a release introduces a new permission, on-chain interaction, or boundary change, that change is also reflected in the relevant Security and Reference pages.
